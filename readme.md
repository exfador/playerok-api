# CXH Playerok 2.1.0

Telegram-панель и автоматизация магазина на Playerok: уведомления, ответы покупателям, автовыдача, автоподтверждение, выставление, поднятие и восстановление лотов.

Сборка основана на исходниках релиза `exfador/playerok-api` 2.0.6 и переработана под текущий API Playerok (контракты сняты с живого фронтенда, все запросы проверены на сервере).

## Что нового в 2.1.0

**API Playerok**
- 40 GraphQL-документов обновлены по живому фронтенду (`pok/contracts/`), генератор `scripts/refresh-contracts.py` обновляет их одной командой.
- Чтение: GET с persisted-хешем и автоматическая регистрация запроса (APQ) при `PersistedQueryNotFound`.
- Мутации никогда не повторяются после неоднозначного ответа; повторная платная операция с тем же лотом блокируется до проверки.
- `markChatAsRead` больше не блокирует отправку сообщений.
- TLS-отпечаток подбирается под версию Chrome из вашего User-Agent.
- Cookie с недопустимыми символами пропускаются, а не роняют запуск.
- WebSocket: корректное рукопожатие, прокси, подписки после `connection_ack`, ping/pong, восстановление.

**Лоты**
- Раздел «📦 Мои лоты» в Telegram: список, карточка, выставить, поднять, «оставлять в продаже», копия лота, удаление.
- Выбор тарифа и экран подтверждения со стоимостью перед каждым платным действием.
- Восстановление: проверка статуса перед оплатой, лимит цены; лоты, которые были PREMIUM, снова выставляются как PREMIUM (если включено платное восстановление), остальные — бесплатно; `keepInSale` для PREMIUM.
- Лоты, для способа получения которых Playerok требует больше отзывов, чем есть у аккаунта, не оплачиваются и помечаются в карточке.
- Копия лота: фото исходного лота скачиваются и загружаются заново, можно выбрать другой способ получения (например, «Подарок» вместо «Со входом в аккаунт»).
- Поднятие: лимит цены, сохранение `keepInSale`, проверка результата при неясном ответе.
- Дневной лимит расходов на автоподнятие и платное восстановление (по умолчанию 200 ₽): при исчерпании платные действия переносятся на завтра, приходит одно уведомление.

**Автоматизация**
- Автовыдача: пустые фразы игнорируются, «100» не совпадает с «2100», выбирается самое точное правило, ключ списывается из актуального файла и возвращается при ошибке отправки.
- Перед автовыдачей сделка проверяется через API (статус оплаты и что лот ваш).
- После обрыва WebSocket бот перепроверяет последние чаты и обрабатывает заказы, оплаченные во время обрыва, без повторной выдачи уже обработанных.
- Автоподтверждение не срабатывает, если товар закончился или не отправился.
- Системные шаблоны сообщений (приветствие, новая сделка, отправлено, завершено, возврат, отзыв, вызов продавца, товар закончился) доступны в панели.
- Список отслеживаемых отзывов ограничен по размеру и времени.

**Надёжность и безопасность**
- Удалён глобальный HTTP-патч, который засыпал на минуты из-за текста в ответе.
- Защита от перебора пароля панели; сообщение с паролем удаляется из чата при любой попытке.
- Раздел «🛡 Доступ»: список администраторов, смена пароля с отключением всех остальных, отключение всех, кроме себя. Отключённый администратор не может продолжить начатый диалог в панели.
- Рассылка автора исходного проекта и проверка его релизов выключены по умолчанию и включаются в «Обновлениях».
- `/logs` сжимает большой журнал в zip и при необходимости отправляет только его конец (лимит Telegram — 50 МБ).
- Текст сообщений и нажатий не пишется в логи.
- Команды и формы панели обрабатываются раньше расширений.
- HTML в уведомлениях экранируется, при ошибке разметки уведомление уходит обычным текстом.

## Установка

Нужен Python 3.11.

Windows:

```powershell
py -3.11 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.lock
.venv\Scripts\python.exe main.py
```

или `start.bat` — он же перезапускает бота после `/restart` и обновления.

Linux:

```bash
bash install_playerok_api.sh
.venv/bin/python main.py
```

Скрипт ставит Python 3.11 (если нужно), создаёт `.venv` и устанавливает зависимости. Каталоги `conf/`, `db/`, `logs/`, `ext/` не трогаются.

## Первый запуск

Мастер попросит токен Telegram-бота, пароль панели, Cookie Playerok (`conf/cookies.json`, экспорт из Cookie-Editor) и User-Agent браузера. Используйте те же IP и User-Agent, что и в браузере, где экспортированы Cookie.

После запуска откройте бота и отправьте `/start`.

## Команды Telegram

| Команда | Назначение |
|---|---|
| `/start` | Главное меню |
| `/status` | Состояние Playerok, WebSocket, Telegram и фоновых процессов |
| `/logs` | Журнал за выбранную дату |
| `/restart` | Перезапуск |

## Конфигурация

| Ключ | Назначение |
|---|---|
| `auto.restore.sold` / `expired` | Восстанавливать проданные / истёкшие лоты |
| `auto.restore.premium` | Выставлять бывшие PREMIUM-лоты снова как PREMIUM и разрешить платный тариф, если бесплатного нет |
| `auto.restore.premium_max_price` | Максимальная цена восстановления, ₽ (0 — без лимита) |
| `auto.restore.keep_in_sale` | Включать «оставлять в продаже» при PREMIUM |
| `auto.bump.max_price` | Максимальная цена одного поднятия, ₽ |
| `auto.daily_limit` | Сколько автоматика может потратить за сутки, ₽ (0 — без лимита) |
| `broadcast.enabled` | Объявления автора исходного проекта (по умолчанию выключены) |
| `auto.confirm` | Автоподтверждение сделок |
| `auto.confirm.only_delivered` | Подтверждать только сделки, по которым бот сам выдал товар (по умолчанию включено) |
| `features.deliveries` | Автовыдача |
| `features.watermark` | Подпись к сообщениям (по умолчанию выключена) |
| `updater.enabled` | Проверка релизов исходного проекта (по умолчанию выключена) |

## Проверка API без запуска бота

```bash
.venv/bin/python scripts/check-playerok.py --cookies conf/cookies.json --user-agent "Mozilla/5.0 ..."
.venv/bin/python scripts/check-websocket.py --cookies conf/cookies.json --user-agent "Mozilla/5.0 ..."
```

Скрипты выполняют только чтение. User-Agent и `--proxy` укажите те же, что в браузере, из которого экспортированы Cookie.

Без `--cookies` `check-playerok.py` проверяет сеть, TLS, DDoS-Guard и разбор ответов на публичном каталоге — без входа в аккаунт.

## Обновление контрактов после изменений Playerok

```bash
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python scripts/refresh-contracts.py --check
.venv/bin/python scripts/refresh-contracts.py --write
```

## Сброс данных

```bash
.venv/bin/python clean.py
.venv/bin/python clean.py --yes
```

Без `--yes` скрипт только показывает, что будет удалено. С `--yes` удаляет `conf/`, `db/`, `logs/` и `__pycache__` — вместе с токенами, Cookie и паролем панели.

## Тесты

```bash
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python -m pytest -q
.venv/bin/python -m ruff check .
```

## Структура

```text
pok/        клиент Playerok: транспорт, контракты, модели, поток событий
bot/        движок: сделки, автовыдача, восстановление, поднятие
ctrl/       Telegram-панель
lib/        конфигурация, база, расширения, обновления
constants/  константы API
scripts/    проверка API и обновление контрактов
tests/      тесты
```

## Ответственность

Проект не является официальным продуктом Playerok. Платные действия (восстановление и поднятие) списывают деньги с баланса Playerok — задайте лимиты цены. Не публикуйте `conf/`, `db/` и логи.
